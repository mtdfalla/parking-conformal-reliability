- **Source:** Belgrade public parking system, raw export.
- **Coverage:** 4 March 2017 15:00 → 21 March 2017 19:22 (~17 days).
- **Sampling:** every 2 minutes.
- **Shape:** 9,706 data rows (after 4 header/blank lines) × 24 columns (1 timestamp + 23 facilities).
- **Quality:** **0 missing / 0 non-numeric cells** across all 232,944 data points.
- **Layout note:** Row 1 is a title; rows 2–3 blank; row 4 holds facility names; data begins row 5.
- **Timestamp format:** e.g. `Sat Mar 2017 04 15:00:59` (weekday, month, year, day, time) — needs parsing.
- **Value meaning:** integer count of cars currently parked in each facility (e.g. `273` = 273 cars).
